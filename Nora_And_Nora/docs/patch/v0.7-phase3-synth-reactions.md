# v0.7.0: Phase 3, Synth Nora on synth-related moments (+ Subversion add-on)

Written 2026-10-23. Script: `docs/script/phase3-script.md` (draft 2, the user's edits). 59 lines voiced with xVASynth
(f4_nora): 32 for the vanilla game, 27 for Subversion. All checked with check_audio.py (44.1 kHz mono 16-bit,
no silence problems; one line clips for 11 samples).

## How it hooks in (no vanilla records edited)
New quest `NN_Phase3` (0xE02, start game enabled), script `NN_Phase3Script` (`tools/phase3.py`):
1. **Dialogue reaction points.** CompanionAffinityEventQuestScript (quest 001C5099) sends the custom event
   CompanionAffinityEvent (quest, sender, eventID) for every flagged player line; companion mods add handlers per quest.
   Synthetic Love has none. We register for it and handle: DialogueBunkerHill #1, MQ105 #1, MQ201 #1/#5, RR101 #1, RR102 #8.
2. **FollowersScript AffinityEvent.** CA__CustomEvent_MQ302EvacuateInstitute (0019B647: line only, SL already reacts)
   and ...DoNotEvacuateInstitute (0019B648: Dislike + line).
3. **Quest stages** (remote OnStageSet): MQ207 150/180 (Shaun talk, waits until she is with you), MinRecruit00 50,
   MQ302Min 1900, RR102 800, MQ302RR 900, BoS101 555, MQ302BoS 900, Inst308 200, MinDestBoS 500 / RR303 1150 /
   Inst307 200, BoS302 120 / 90 / 170, MS17 500 / 600 / 740, Inst301 500. Stage meanings from the quest logs.
- Each moment plays once (its NN_Phase3 stage marks it), only when synth Nora is a current companion within 3000 units.
  Reaction via FollowersScript.SendAffinityEvent with SL's keyword, then her line (Say), then Organic Nora's reply if
  she is with you. P3-FC-023 only at tier 3+. The Minutemen, Railroad and Brotherhood endings are followed by the
  "Institute destroyed" exchange (FC-050/051, no second reaction).

## Subversion add-on: NoraAndNora - Subversion.esp
Masters: Fallout4, NoraSpouse, p865_SyntheticLove, NoraAndNora, InstituteReformation. Quest `NN_Subversion` (0x81B)
watches zzReformQuest 20/57/75/88, zzMarch 10, zzDirector 13, zzPiper 100, zzHope 20, zzNextLevel 100,
zzSAllGoodMan 100, zzInstantKarma 100. Moments wait (pending stage = stage+1, polled every 6 game minutes) until synth
Nora is with you and nobody is fighting. After the synths are freed, at tier 2+, scene `NN_SV_AmI` ("They're free...
am I?") with four answers; "not the same" calls NN_Phase2Script.HurtUp. FOMOD: new "Other mods" step, shown as
usable only with InstituteReformation.esp.
