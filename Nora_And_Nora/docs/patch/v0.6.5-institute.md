# v0.6.5: Synth Nora comes along to the Institute

Written 2026-10-23. Asked for: synth Nora should get into the Institute the way Organic Nora does.

- The Institute is reached by teleport, so companions are left behind unless a script moves them. Vanilla's
  InstituteTeleportEffects (001ED4FA) only handles X6-88; Nora Spouse adds COMNoraInstituteTeleportEffects for its
  Nora (moves her to MQ302FollowerInstituteTeleportRef 001D3323 and casts TeleportPlayerInSpell 001E5601). UCF has
  nothing for this.
- New quest `NN_SynthNoraInstitute` (0xE01, start game enabled), script `NN_InstituteTeleportScript`
  (`tools/institute.py`): registers for the player's OnLocationChange; on going from outside to inside
  InstituteLocation (000681AC), if MQ207 stage 200 is done and synth Nora is in CurrentCompanionFaction, she is moved
  to the same marker with the same teleport-in spell. Inside/outside test copied from vanilla
  InstituteTeleportQuestAliasScript.
- verify_refs 0 problems (UCF, NoUCF). Untested in game.

Also this day: Synth Nora reactions set from the user's comments in the reactions doc, and Phase 3 script draft 1
(`docs/script/phase3-script.md`).
