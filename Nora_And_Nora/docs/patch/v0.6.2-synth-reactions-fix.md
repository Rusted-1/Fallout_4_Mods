# v0.6.2: Synth Nora's reactions on existing saves

Written 2026-10-22, after the first in-game test of v0.6.1.

## Reported in game
1. No "liked / disliked / hated that" pop-ups.
2. The test tape note does not show up in the inventory.

## 1. Reactions: cause and fix
`FollowersScript.SendAffinityEvent` returns silently unless the event keyword is in the Followers quest's
`AffinityEvents` array (`GetAffinityEventData`, read from vanilla `followersscript.pex`). The companion side
(`CompanionActorScript`) never hears about the event in that case.

`AffinityEvents` is a script property. Its value lives in the save, so a plugin edit to the Followers quest
(Synthetic Love's own edit, or our UCF merge from v0.1) does not reach a game where the Followers quest
already ran. Synthetic Love's four keywords (Likes 26CD, Loves 26CE, Dislikes 26CB, Hates 26CC) are
therefore missing in a running game, so every Synth Nora reaction is dropped. *Inferred from the scripts;
confirm in game.*

Nora Spouse avoids this: `NoraFollowerDataScript` (quest COMNoraAffinityQuest) appends her events at
runtime in `OnInit`. v0.6.2 does the same for Synthetic Love:

- New quest `NN_AffinitySetup` (0xE00, start game enabled) with `NN_AffinitySetupScript`.
- Its `AffinityEvents` property holds Synthetic Love's four entries (same EventSize 00018CFF and CoolDownDays
  000A1B7C as Synthetic Love's own record).
- `OnInit`: for each entry, if `FollowersScript.GetAffinityEventData(keyword)` finds nothing, append it to
  `FollowersScript.GetScript().AffinityEvents`. Already-present events are skipped.
- In both UCF and NoUCF plugins. Tools: `tools/affinity_setup.py`, wired into `tools/build.py`.

If Nora Spouse's own reactions are missing too, this is not the whole story: her events are registered at
runtime already, so a Papyrus log is needed.
