# v0.6.3: fixes from the first test pass

Written 2026-10-23. Five problems reported in game on v0.6.1/v0.6.2.

## 1. Test tape note never handed over
- `sqv NN_TestTapeGiver`: quest running, script attached, property filled. `player.additem` works and the
  menu opens, so the note and its script are fine.
- The giver quest was flagged **Run Once**, so `stopquest`/`startquest` could not restart it, and its
  `OnQuestInit` had already passed in the save without adding the note (likely too early in the load; not confirmed).
- Fix: new quest `NN_TestTapeGiver2` (0x805, start game enabled, not Run Once), script `NN_TestTapeGiver2Script`:
  `OnInit` registers for the player's `OnPlayerLoadGame` and starts a 5 s timer; the timer gives the note if the player
  has none. Runs again on every load, so a lost note comes back. The old quest 0x804 keeps its form ID with no script.

## 2. Cold Comfort missing from the quest list
- Cause: Cold Comfort (Synthetic Love, 000F9B) has two objectives. Our recruit fragment hid objective 20
  ("…examine the corpse"); with nothing displayed, the quest drops out of the Pip-Boy.
- Fix (`tools/cold_comfort.py`): our plugin overrides Cold Comfort. Objective 20 now reads "Go to Vault 111 with both
  Noras" and its marker alias points at the spouse cryo pod (was the vanilla spouse corpse, unused by SL's scripts).
  The record is the same in all 8 SL versions apart from master indexes and an unused DNAM byte.
- Our own "Two Noras" objective is no longer displayed (it duplicated this one).
- Existing save: `setobjectivedisplayed p865_COMNoraQuest01 20 1` brings it back.

## 3. Vault 111 scene sometimes never completes
- Cause: the greeting that starts the scene set stage 150 on its first line and required 150 not done. If the scene was
  cut off (combat, walking off, closing the dialogue), it could never start again. It also needed SL's cryo trigger
  (SL stage 30), which only fires if synth Nora is a current companion when you cross it.
- Fix: the greeting now requires stage 500 (scene finished) not done, so it retries; and it fires on SL stage 30
  **or** synth Nora in the Vault111Cryo cell (GetInCell 000016D8).

## 4. "Advance to next tier" needs several clicks
- By design each click is one step (check-in talk, Nora's talk, tier 2, …), but the queued talk only played on the
  next 6-minute poll, so clicks seemed to do nothing.
- Fix: `DebugAdvance` now tries the talk immediately and shows a notification: playing now, or queued (Nora not
  close / combat / scene) or relationship advanced.

## 5. Return dialogue after "I need time" never fires
- Cause: the vault-wait greeting only checked the Phase 2 `Waiting` global, set by the tier-3 version of the choice.
  The Vault 111 scene's "I need time" uses Phase 1 stage 200, which never set it.
- Fix: a second greeting (INFO 0xBC4, voice copied from 947) fires while Phase 1 stage 200 is done and 100/300/400/410
  are not. Its answers go to Phase 1's own stages (`Outcome` → `P1Waiting`): come with me → 100 (re-recruit, tier 1),
  I need more time → still waiting, abomination → 300, go your own way → 400.
