# v0.5.1 — Phase 1 voice files

## What changed
- Added the 89 Phase 1 voice lines, generated in xVASynth (Steam, v3.0) with the Fallout 4 `f4_nora` xVAPitch model
  and the "Lip and Fuz Generator" plugin.
- The installer now always installs `Voices/` → `Data/Sound/Voice/NoraAndNora.esp/PlayerVoiceFemale01/` (`.fuz` only;
  `.wav` and `.lip` are packed inside each `.fuz`).
- `fomod/info.xml` version 0.5.1. Plugins and scripts unchanged from v0.5.0.
- `docs/script/phase1-xvasynth-batch.csv` now has the voice ID filled in (`f4_nora`).

## Checks
- 89/89 files present, one per INFO 0x900–0x958. Every voiced INFO in both `UCF/` and `NoUCF/NoraAndNora.esp` has a file, and no file is orphaned.
- Every `.fuz`: `FUZE` v1, lip size matches, audio RIFF XWMA, 44.1 kHz mono. Same structure as Nora Spouse's own `.fuz` files.
- Source WAVs (`tools/check_audio.py`): 44.1 kHz mono 16-bit, normal speech rate, no long silences.
- Minor: 00000908, 00000954 and 00000957 have a few clipped samples (≤14 each). Peaks are normalized near 0 dBFS, so lines may play a bit louder than vanilla dialogue.

## Untested
- In game: lip sync, volume relative to vanilla lines, and that each line plays in its scene.
