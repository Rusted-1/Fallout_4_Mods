## Plugin
`NoraAndNora.esp`, ESL-flagged `.esp`, HEDR 1.0, form version 131 (old-runtime safe). Next object ID 0x800 (ESL range).

| Variant | Masters | Records |
|---|---|---|
| `UCF/` | Fallout4.esm, NoraSpouse.esm, p865_SyntheticLove.esp, EFF.esp | `Followers` (000289E4) merge, see analysis 02 |
| `NoUCF/` | Fallout4.esm, NoraSpouse.esm, p865_SyntheticLove.esp | None yet (Nora Spouse can't overwrite Synthetic Love's Followers edit). Placeholder for the Kellogg fix and later content |

No DLC masters, which is what lets one plugin work with all 8 Synthetic Love versions.

## Installer
One step, "Companion Framework": UCF yes/no, pre-selected from whether `EFF.esp` is active. The UCF option is marked unusable if `EFF.esp` is missing.

## Decisions from planning
- Install via a FOMOD for Vortex. I originally asked for an option per Synthetic Love version. Not needed: all 8 share record IDs. Revisit only if a later feature touches version-specific loadout records.
- UCF is expected but optional. Follow mode (both as companions vs synth Nora tagging along behind real Nora) will be a FOMOD option once the feature exists; it's the forced default without UCF. Also an in-game toggle.
- Voice: splice vanilla `PlayerVoiceFemale01` lines where possible; write every other line into a script sheet for a free AI voice tool (kept in house, not published).
- Synth Nora's romance fires at max affinity (Infatuation); the real Nora's reaction depends on their relationship tier.
- Death-site encounter via Random Encounter Framework. Synth Nora in T-51c power armour if stable; light combat armour arms and medium combat armour torso/legs on her or in her inventory.
- Stimpack aid between the Noras: scripted and throttled.
- I always meet the human Nora first, at Abernathy Farm.
