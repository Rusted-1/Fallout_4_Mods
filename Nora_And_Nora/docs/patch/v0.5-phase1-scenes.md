# v0.5.0 — Phase 1 dialogue scenes

All of `docs/script/phase1-script.md` is now in the plugin, built without the Creation Kit (`tools/phase1_scenes.py`).
A visual overview with every line is in `docs/script/phase1-scenes-overview.html`.

## Quest `NN_P1Scenes` (0x808, "Two Noras")
- **Start and priority:** start-game enabled, priority 90.
- **Aliases:** `SynthNora` (Synthetic Love's `000FB3`) and `Nora` (Nora Spouse's `001735`).
- **Objective 10:** "Travel with Nora to Vault 111". It replaces Synthetic Love's "...examine the corpse", which the scenes hide.
- **Stages:**
  - 13 / 31–34 / 41–44 / 73: choice flags
  - 100: met (with the confrontation)
  - 110: met alone
  - 150: at the vault
  - 500: done

## How the scenes start
- **Greetings, topic `NN_P1_Greetings`:**
  - "Oh my God... Nate?" plays when Synthetic Love's quest is below stage 10 and Nora Spouse's "O Spouse, Where Art Thou?" stage 20 is done. It starts **S1**.
  - "Here. Here it is." plays at Cold Comfort stage 30, after the meeting, with the real Nora in the companion faction. It starts **S2**.
  - Our quest priority (90) is above Synthetic Love's (71), so these greetings win over Synthetic Love's own while the conditions hold. Its records aren't edited.
- **`NN_P1ScenesScript`:**
  - **S1C:** after the solo meeting (stage 110), plays when the two Noras first come within 1000 units of each other.
  - **Road exchanges:** about every 20 game hours, before the vault, if the real Nora is with you.
  - **SK:** plays on synth Nora's death after choice 3.
  - **NT:** plays when the note is read (`NN_Phase1` stage 430).

## Line scripts
`NN_P1S_TIF` (one shared TopicInfo script):
- **`Frag_31..44`, `Frag_73`, `Frag_13`:** set choice flags.
- **`Frag_Met` / `Frag_MetAlone`:** Synthetic Love stages 10 and 20 (its own recruit logic), hide its objective, show ours.
- **`Frag_AtVault`:** sets stage 150.
- **`Frag_Out100..400`:** complete Cold Comfort (stage 40) and our objective, then set `NN_Phase1` 100/200/300/400, which run the v0.3 outcome system.

## Lines
- **Spoken lines:** each one has its own topic with one line, under the form ID reserved in the voice sheet (`0x900`–`0x958`). So recorded files named `<ID>_1` match automatically.
- **Facial emotion:** taken from the delivery notes, e.g. "cold" → Stern, "begging" → Pleading, otherwise the sheet's emotion tag.
- **Nate:** 38 text-only lines (`0xA00`+). With XDI the wheel shows the full line; without it, the label.
